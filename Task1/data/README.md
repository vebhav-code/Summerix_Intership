## 1. Student Performance dataset (`student_data.csv`)

### Basic information

| Item | Details |
|------|---------|
| **Dataset name** | Students Performance in Exams |
| **Original source** | Kaggle - <https://www.kaggle.com/datasets/spscientist/students-performance-in-exams> (uploaded by "spscientist"; described there as "Marks secured by the students in various subjects") |
| **How this file was obtained** | **Downloaded** (not generated by this project). It was fetched from a public GitHub copy of the Kaggle file: <https://github.com/rashida048/Datasets/blob/master/StudentsPerformance.csv>. It was **not** downloaded from Kaggle directly. |
| **Number of rows** | 1000 (one row per student) |
| **Number of columns** | 8 (5 categorical, 3 numerical) |
| **License** | Listed as **"Unknown"** on the Kaggle page. |
| **SHA-256 of the file** | `6ba534ef45b180c7fe8a1f681f2e9dc33924a9593243df221dac002c90b11cc1` |

### Provenance and limitations (please read)

* The Kaggle page does **not** explain how the data was collected, and this project has not verified it.
  A different Kaggle dataset with the same kind of columns describes itself as *fictional* and
  generated with an online tool; the Kaggle page of this dataset makes no such statement, so its
  origin is **unverified**. It is best treated as a practice/illustrative dataset. Conclusions from
  the analysis apply to **this dataset only**, not to real student populations.
* Because the license is listed as "Unknown", check the terms before republishing the CSV file
  outside of this internship (for example in a public GitHub repository).
* The GitHub copy was not compared byte-for-byte with the Kaggle original. Its summary statistics
  (for example a mean math score of 66.089) agree with those reported in other public analyses
  of the Kaggle dataset.

### Column descriptions (raw file)

| Column | Type | Values in the data | Description |
|--------|------|--------------------|-------------|
| `gender` | categorical | `female`, `male` | Gender of the student. |
| `race/ethnicity` | categorical | `group A` ... `group E` | Anonymized group label of the student. The dataset does not say what the groups mean. |
| `parental level of education` | categorical (ordered) | `some high school`, `high school`, `some college`, `associate's degree`, `bachelor's degree`, `master's degree` | Highest education level of the student's parent(s). |
| `lunch` | categorical | `standard`, `free/reduced` | Type of lunch the student receives. The dataset does not explain this further. |
| `test preparation course` | categorical | `none`, `completed` | Whether the student completed a test-preparation course. `none` is a real category (course not completed), **not** a missing value. |
| `math score` | integer | 0 - 100 | Score in the math exam. |
| `reading score` | integer | 17 - 100 | Score in the reading exam. |
| `writing score` | integer | 10 - 100 | Score in the writing exam. |

The scores are whole numbers on a 0-100 scale (the observed minimum and maximum of each column are
shown above).

### Cleaned file (`cleaned_student_data.csv`)

Created by the cleaning code in `src/data_cleaning.py`. This serves as the clean handoff file for **Task 2** (supervised machine learning). Compared with the raw file:

* Column names are lowercase `snake_case`: `race_ethnicity`, `parental_education`, `test_preparation`,
  `math_score`, `reading_score`, `writing_score` (`gender` and `lunch` keep their names).
* Text values are stripped and lowercased (for example `group A` becomes `group a`).
* No rows were removed and no values were imputed: the raw data contains **no missing values and no
  duplicate rows**, so it still has 1000 rows and 8 columns.
